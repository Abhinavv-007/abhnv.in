    Setting a default family member

    Auto-select a family member when adding new subscriptions to save time

    Save Time with Default Selection

    Save time by setting a default family member who will be automatically selected when you add new subscriptions. This is perfect if most subscriptions belong to one person (usually yourself).

    Why Use a Default Member?

    If you're the primary subscriber in your household, setting yourself as the default means you won't need to manually select your name every time you add a subscription. It's a small time-saver that adds up when tracking multiple services.

    How to Set a Default

    1. Go to the Family Members section
    2. Find the family member you want to set as default
    3. Click the Set as Default option
    4. Confirm your selection

    What This Does

    When you add a new subscription:

    • The default family member will be automatically pre-selected in the assignment dropdown
    • You can still change it to someone else if needed
    • This doesn't affect existing subscriptions

    Changing the Default

    You can change the default family member at any time by following the same steps. Simply set a different member as the default, and all future subscriptions will pre-select them instead.

    Note: Setting a default is optional but highly recommended if one person manages most of the household subscriptions.
