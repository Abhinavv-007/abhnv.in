    Checkout not working

    Troubleshooting steps if you're experiencing issues with the checkout page

    Checkout Issues? Here's How to Fix Them

    If you're seeing errors at checkout or the payment page won't load, try these solutions:

    Solution 1: Disable Ad Blockers

    Ad blockers can interfere with payment processors. This is the most common cause of checkout issues.

    • Temporarily disable your ad blocker (uBlock Origin, AdBlock Plus, etc.)
    • Refresh the page and try again
    • You can re-enable it after completing your purchase

    Solution 2: Try a Chromium-Based Browser

    Some browsers have better compatibility with our payment processor.

    • Use Google Chrome, Microsoft Edge, or Brave
    • These work more reliably than Firefox or Safari
    • If you're already using Chrome, try opening an incognito window

    Solution 3: Checkout From the Landing Page

    The dashboard checkout sometimes has issues - the landing page works more reliably.

    1. Go to subtrack.abhnv.in (the main landing page)
    2. Click on "Pricing" in the navigation
    3. Select your plan from the pricing section
    4. Complete checkout from there instead

    Still Having Issues?

    If none of these solutions work:

    • Contact support via LinkedIn DM (@Vu Nguyen)
    • Include a screenshot of any error messages
    • Mention which browser and device you're using
    • We'll help you complete your purchase
