# SubTrack (Frontend)

This is the SubTrack subscription tracking application frontend.

## How to Run

1.  Open your terminal in this directory.
2.  Run `npm install` (optional, as `npx` handles binaries, but good to have).
3.  Run `npm start`.
4.  Open [http://localhost:3000](http://localhost:3000) in your browser.

## Structure

-   `index.html`: The main landing page.
-   `dashboard.html`: The dashboard view.
-   `_next/`: Static assets (JS, CSS, Images).
-   `api/`: Static API responses (if locally available).
